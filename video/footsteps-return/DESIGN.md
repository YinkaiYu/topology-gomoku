# 《足音回归》PV 视觉设计契约

本合成继承 [`docs/design/visual-language.md`](../../docs/design/visual-language.md) 的“简约、典雅、克制”与液态玻璃原则。画面以棋局与曲面的空间关系为主，材质只用于区分层级，不能压过玩法对象。

## 画布与安全区

- 母版固定为 3840×2160、60fps、16:9；所有章节在这一母版内制作。
- 安全区为左右各 192px、上方 144px、下方 180px。标题、叙述、字幕、徽标和关键棋子都必须留在其中；全出血拓扑图形可越过安全区。
- 主镜头是正交或近似正交的缓慢观察镜头。只使用连续平移、推近、拉远、绕中心轻微旋转；不使用手持抖动、快速甩镜、夸张透视或突然变焦。

## 调色板与章节光

所有颜色直接沿用游戏现有的颜色令牌：

| 用途 | 色值 |
| --- | --- |
| 纸本底色 | `#f2efe7` |
| 深纸本 / 阴影基色 | `#e8e2d7` |
| 墨色文字与线条 | `#21302c` |
| 次要说明 | `#817f77` |
| 红色落子光 | `#d95b4f` |
| 青绿色曲面光 | `#3f8c87` |
| 深蓝色双周期光 | `#385f78` |
| 金色胜势光 | `#c79244` |
| 棕褐空间光 | `#8b7556` |
| 紫色非定向光 | `#7f6ca8` |

章节只在一个主光色内推进：平面使用墨色，圆柱使用青绿色，环面使用深蓝色，莫比乌斯带使用红色，球面使用金色，克莱因瓶使用紫色，射影平面使用棕褐色。高光应局部、低饱和并服从纸本底色；不加入彩虹渐变或霓虹轮廓。

## 字体与字幕

- 使用仓库内嵌的 `Topo Serif`（400/600/700）。标题为 600 或 700，说明与字幕为 400；不以系统字体回退作为正常结果。
- 主标题最小 96px，章节标题最小 72px，字幕最小 42px；数字使用 `font-variant-numeric: tabular-nums`。
- 字幕位于底部安全区上缘，单行优先、最多两行，居中，墨色文字配受控的半透明纸本底板；不得使用逐词弹跳、描边、发光、卡拉 OK 高亮或整屏遮罩。

## 章节牌

- 章节牌只有两级视觉层级。阶段 A 的上层为单行 `ACT. III`、下层为关卡名 `扭带`；阶段 B 在同一上层槽位切换为流形名 `莫比乌斯环`，下层 `扭带` 的位置、透明度与字号保持不变。
- 两行整体以画布 50% 水平中轴居中；上层槽位、`ACT.`、流形名和下层关卡名共享同一几何中心，文字为居中对齐，A/B 切换及中间帧都不得产生水平偏移。
- `ACT.` 与流形名采用短交叉淡化和最多 3px 的轻微焦点过渡；两者不得同时完整可见，也不使用横向滑动、擦除、扫光、逐字、弹跳或夸张缩放。
- 阶段 A、切换、阶段 B 由可调时间数据管理，在约三秒章节牌中分别保留可读停留。背景仍为近黑空间、低对比拓扑轮廓和微弱体积光。
- 章节牌标题只在画面显影，不进入旁白或字幕；定稿正文中自然出现的同词不受影响。

## 镜头与运动

- 每个镜头先停留以建立阅读，再发生一次清晰的空间变化；棋子、曲面、文字的运动都要解释拓扑关系或叙事推进。
- 进入遵循由弱到强的 0.3–0.8 秒缓动，镜头间保持对象身份连续；不使用无意义的持续漂浮、无限循环、跳切、闪白或冲击缩放。
- 材质效果仅允许轻微透光、受控边缘光和低对比阴影。禁止大面积乳白磨砂、硬色带、过强彩边、镜面高光、塑料质感、故障风、粒子雨和镜头光晕。

## 七章主体

- 每章只挂载一个持久 `render-game.html` iframe，并由同一个透明真实 Canvas 连续完成建立、逐颗落下 1–5、最终五连、形变、成形停留与有限旋转；seek 只重建状态，不重载 iframe 或剪接片段。
- 所有跨界前先显示无文字的延长呼吸辅助线。环面和实射影平面完整呈现两次跨界；克莱因瓶先在同一 Canvas 稳定保持方向路径的完整五连，再经由平滑淡出的成对记忆阶段清盘，随后完成翻转方向路径 1–5，仅第二条连接形变。
- 平面保持真实棋盘形变恒等，仅由母版摄影层抬升和倾斜；其余六章的拓扑证据来自游戏内 `TopologyMorph` 与原有规则路径。Three.js 只提供低对比空间暗影、景深与有限粒子，不替代真实棋盘形变。
- 棋盘保持居中、完整、无手机或平板外框，不叠加说明文字。每章末尾只提供真实棋盘到流形再到几何 / 暗影遮蔽的可挂接出口；相邻镜头由 `runtime/transitions.js` 统一编排真实几何遮蔽、受控焦点拉动、短黑沉和轮廓 match-cut，不使用页面位移或擦拭。

## 七流形汇聚与转场

- `seven-worlds.js` 只挂载平面、圆柱面、环面、莫比乌斯环、克莱因瓶、实射影平面、球面各一次；路径来自 `src/data/game-render-shots.js` 的真实 demo，按章节顺序点亮并允许既有跨界路径并存，不合成虚构跨多边界路径。
- 关键轮廓契约固定为“圆柱截面 → 环面内环 → 莫比乌斯扭转中心 → 克莱因交叉”；其他相邻对使用当前曲面出口与下一章牌轮廓的明暗或运动惯性匹配。gallery 镜头只缓慢退出，片尾标题前保留音乐尾音与静默空间。
- 母版 timeline 始终暂停、有限且可逆；gallery 不含章节标题、总结句或装饰连接线，所有转场层均为独立黑色遮蔽层，不移动页面布局。

## 资产边界

合成直接复用 `app/assets/fonts/` 中的 Topo Serif 字体，以及 `app/assets/topologies/` 和 `app/assets/silhouettes/` 中的现有拓扑 SVG。生成的配音、配乐、临时帧序列与渲染文件一律留在本地生成目录，不纳入 Git；只有 `docs/design/qa.md` 登记的精选基线或联系表可进入 `artifacts/` 作为长期回归证据。
