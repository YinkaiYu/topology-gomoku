# 拓扑五子棋

一款为小红书小工具容器设计的离线小游戏。玩家在平面、圆柱、莫比乌斯带、环面、克莱因瓶等拓扑棋盘上与本地 AI 对弈，逐关解锁新的边界规则。

除常规五连外，当玩家已经截断 AI 的全部合法五连路径时，也会立即获胜，避免小棋盘频繁进入平局。

进入每一关时，棋盘会用五颗连续落子直观演示当前边界；跨越接缝时，对应边轨同步亮起。规则以克制的常驻文字融入棋盘下方，点击棋盘可略过演示，重开本局则直接进入对弈。

关卡目录使用统一的二次元手绘实体剪影：拓扑曲面由确定性几何生成，经过深度排序形成不透明遮挡，再用暖白块面、分层灰褐阴影与轻微抖动的深色描边完成赛璐璐式渲染；莫比乌斯带按真实单一边界描线以显出翻面，克莱因瓶采用由已验证浸入约束的经典回环穿颈示意。不绘制透明经纬网格或文字注释。生成脚本会验证周期闭合、反向粘合与实射影平面的对径不变性。

从第二关开始默认启用落点提示：玩家形成活三时圈出两端，形成单边四子时圈出第五点；所有提示都沿真实拓扑路径计算，并可在设置中关闭。

残局会尽早结算：只要任一方已经不存在任何仍可完成的五连路径，就不再要求玩家陪 AI 填满棋盘，直接判定玩家通关。对手分为悠闲、敏捷、深思三档；悠闲档会主动避开大量关键点，深思档保留完整搜索强度。

第一关是无 AI 的五子棋教学：状态栏用极短的落子计数提醒玩家继续操作，棋盘内的同一句提示会跟随呼吸虚线圈出现在自然延伸点上方；玩家连续落下五颗并连成一线即可进入第二关。从第二关开始，通关后会把保留当前棋子的二维棋盘按本关边界条件连续粘合为光滑的三维拓扑曲面；棋盘经高密度曲面采样后自然弯曲，真实五连会随曲面一起变形并保持高亮。

胜负结算都不会弹出遮挡棋盘的卡片：三维曲面会留在原位持续缓慢旋转，玩家可直接拖动并以惯性从不同角度欣赏。成形使用带轻微回弹的连续插值，并自动搜索让五连朝向观察者的视角；最终五点会被连续收束为等距的轻弧路径，避免克莱因瓶与实射影平面的参数化造成不均匀拉伸。旅程、再来与下一关操作克制地留在棋盘下方。

目录同时是一册拓扑图鉴：除第一关外，尚未通关的几何体只显示带问号的实心剪影；手动解锁仅开放游玩资格，必须真正通关后才会揭示完整图形。

未揭示剪影直接由对应关卡的真实拓扑 SVG 压暗得到，不再使用通用占位轮廓。开发者模式的“玩家胜利”会沿该关边界演示路径逐颗落下跨界五连；自由拖动三维曲面时，曲面会随手势产生轻微柔性滞后与回弹，同时保持拓扑接缝重合。

首页关卡卡片就是入口：点击后卡片以共享元素动效展开成棋盘；返回时，同一运动载体会在收束途中由棋盘内容连续过渡为对应图鉴卡片，进入与返回都采用预绘制双帧交接，动画层撤下前静态层已经完成绘制，避免末尾闪烁。下一关与重开也使用方向明确的弹性切换。目录卡片不显示编号，几何注释仿照拼音置于居中的关卡名上方。未揭示图鉴只保留由真实模型生成的实心最外轮廓，不显示内部孔洞。目录页取消设置按钮并锁定整屏布局，禁止页面滚动；在为小红书宿主按钮保留适量空间的同时，让六关在较矮的手机视口中也完整可见。E 款墨色环结图标作为标题右侧的大幅主视觉，上传用白底版本位于 `release/topology-gomoku-icon.png`。

全界面内嵌经过精简的思源宋体三档字重，不依赖系统字体，也不会在 iPhone 上自动退回苹方；字体许可证位于源码仓库的 `licenses/OFL.txt`。

## 技术方案

- 原生 HTML / CSS / JavaScript
- Canvas 2D 棋盘与动效
- Web Audio 即时合成音效
- 本地 AI 与 `localStorage` 进度存档
- 无运行时依赖、无网络请求

## 开发与验证

直接打开 `app/index.html` 可以预览。建议通过本地静态服务器预览，以贴近 WebView 行为。

```powershell
npm test
npm run validate
npm run build
```

构建产物输出到 `release/topology-gomoku.zip`，其中 `index.html` 位于压缩包根目录，可直接交给小红书小工具模拟器。

## 开发者模式

在预览地址后添加 `?dev=1` 启动，例如：

```text
app/index.html?dev=1
```

也可以使用 `app/index.html#dev`。启动后点击顶部的 `DEV`，可以暂停 AI、切换黑白落子、强制任一方胜利、清空棋盘，以及手动解锁或重置关卡进度。普通启动不会显示这些控件。
