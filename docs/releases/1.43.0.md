# 1.43.0 发布说明

2026-11-10，用户确认渲染预览并授权将稳定 `dev` 提升至 `main`，统一版本为 1.43.0，完成各渠道发行。

- 曲面相交处增加暖白轮廓和柔和光晕，改善双生、瓶界及展开过程的结构辨识；棋子与曲面的接触线保持克制。
- 两组边界分先后粘合，先向外舒展再沿弧线收拢，并保留方向箭头与扭转样式。归圆、圆筒、环游、扭带的过渡避免不必要的自交。
- 补齐二维边界四角；展开初始画面连续保留网格点、材质和棋子，往返切换不再突然跳变。

共享产品基线为 `dev@813c023`，版本准备提交 `6df73bf` 已提升为稳定 `main@d99166a`（标签 `v1.43.0`）。提升前后均通过 239 项测试、H5 资源与文档校验；同状态截图、首帧像素对照及真实曲面相交检测见[视觉 QA](../design/qa.md)。本轮平台整合均从同一稳定 main 提交开始，平台适配不改变游戏版本。

## 验证范围与限制

- 用户已确认本轮预览与修复效果。浏览器验证覆盖六类曲面、二维与三维往返、落子动作、方向箭头及不同棋盘尺寸。
- 常见少量棋子场景约 30–60 帧/秒；19×19 满盘双生的精确遮挡与相交计算仍有明显开销，已测约 12 帧/秒。
- 平台上传、审核和上线分别记录；浏览器模拟视口不代替手机真机验收。

### 平台验证与限制

- 小红书使用官方 CLI 1.0.5 正式环境，保留原名称、简介、图标、封面与权限。手机预览和送审绑定同一 ZIP；用户明确确认通过后提交，历史记录确认 1.43.0 审核中，不能将已接收送审写成已上线。本轮官方本地模拟器成功加载首页、双人入口与双生三维，细粒度落子自动化受嵌套 iframe 坐标限制；手机功能由用户验收。
- 小红书当前在线规范已复核；本轮继续已验证的产品基线，未混入此前未经确认的存储兼容改写。Chrome 61 兼容与原生 Storage 迁移仍是既有后续事项，目录/体积审计不证明这些兼容性通过。产物未启用 Worker、OffscreenCanvas、WASM 或第三方游戏引擎，保留 `is_high_consumption_scene: false`。
- Bilibili 检查真实预览与本地源的四份脚本哈希，审核后再次查询 `published`；未将模拟浏览器检查表述为 App 真机验收。
- 微信原生调用边界同步共享近零进度契约，绘制、拖动与命中保持一致，独立审查通过；共享 `app/` 与 main 相同。原生浏览器校准覆盖 14 组拓扑、56 次角落落子和 12 次三维落子，官方模拟器首页正常。官方坐标自动化仍无可见响应，并存在 `jsbridge not ready` 工具侧限制，未将该环节写成通过。长期分支再次通过 297 项测试后 fresh build/sync，64 文件原生包 1196.4KB，配置哈希保持。用户确认官方上传后，查询原任务得到 `success / execution_success`；CLI 不提供公众平台提审能力，提审留给用户，未声称已审核或上线。
- Web 上轮部署问题已由网站此前更新解除，本轮只替换 `show/topology-gomoku/` 内五份游戏脚本；[Pages 运行](https://github.com/YinkaiYu/YinkaiYu.GitHub.io/actions/runs/42812605033)成功。部署副本的桌面/手机设置、落子与偏好持久化通过；正式站点的四份脚本哈希、落子、旋转和展开交互核验通过。
- 知乎使用当前官方 Skill 1.2.0 生成隔离静态交付副本，由平台部署；Agent 未创建或修改云资源。内置浏览器复用机构登录完成上传，未更改 Edge 的个人账号；[公开作品页](https://www.zhihu.com/project/detail/180488)显示 V 1.43.0，审核提示消失，游戏正常加载。
