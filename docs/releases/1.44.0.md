# 1.44.0 发布说明

2026-11-12，用户确认本轮预览，授权合并并发布统一版本 1.44.0。

- 瓶界先卷成圆筒，再沿宽缓弧线收拢；瓶肚保持圆润，瓶口在末段穿入瓶身，与瓶底内部接合。

- 修复归圆五子连线跨边界时绕入棋盘的问题。
