# 1.44.0 发布说明

2026-11-12，用户确认本轮预览，授权合并并发布统一版本 1.44.0。

- 瓶界先卷成圆筒，再沿宽缓弧线收拢；瓶肚保持圆润，瓶口在末段穿入瓶身，与瓶底内部接合。
- 双生先基本形成扭带，绿边从箭头向箭尾逐段直接粘合。
- 任意非零展开进度的视角拖动保持同样响应，二维往返连续。
- 修复归圆五子连线跨边界时绕入棋盘的问题。

共享产品提交为 `1c66e25`，Arena 对应提交为 `559c311`。共享 249 项、Arena 350 项测试以及资源、文档检查已通过；同状态视觉证据见[视觉 QA](../design/qa.md)。

## 验证边界

各渠道 QA 证据随各自发行提交记录于 docs/design/qa.md。微信浏览器原生校准覆盖七种拓扑、28 次角点和六次投影落子，官方模拟器首页正常；工具日志仍有历史 jsbridge not ready 错误，不代表手机真机验收。微信公众平台提审由用户完成。小红书和知乎送审成功不等于已经上线。

小红书继续既有已验收产品基线，Chrome 61 和原生 Storage 迁移仍属后续兼容事项，未混入未经确认的改写。知乎由平台部署静态交付物，未由 Agent 创建云资源；使用内置浏览器机构账号，未操作 Edge 个人账号。另一任务的豆包连接器未并入本次发行。
