# 1.41.0 发布说明

新增离线同设备双人对弈，关联 Issue #2。用户于 2026-10-20 确认最终预览并授权收尾发布。

- 首页提供左对齐的“人机对弈 / 离线双人”，移除重复旅程与模式标签。
- 双人可直接进入全部七关，黑白交替落子，支持五连胜负、满盘和局、单步悔棋、重开与退出；不调用 AI 或网络。
- 边界演示后恢复原对局，双人不会授予人机难度等级。
- 接收既有 1.40.0 窗口适配；极矮窗口保留完整卡片。

共享验证：151 项测试、H5 包与文档校验、双视口离线对局、九种首页窗口、七种棋盘窗口与面板缩放落子检查通过。同视口证据见 [视觉 QA](../design/qa.md)。

## 发行状态

统一版本 1.41.0，所有渠道从同一稳定 main 接收。渠道整合与上传正在执行；构建完成不代表线上生效，实际结果在本记录补充。
