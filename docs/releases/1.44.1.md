# 1.44.1 发布说明

2026-11-12，用户确认 iPhone 实机 A/B 预览并授权提升与发布修复版本。

- 修复三维棋盘后方棋子在 iPhone 上不正确地显示为不透明的问题。
- 完全遮挡与局部遮挡统一采用无阴影的淡色绘制，保留背面影像。

共享修复 `39439f6`；250 项测试、资源与文档校验通过。用户在同一台 iPhone 上确认修正版正常、旧版仍异常；桌面 Chromium / WebKit 回归及真机验证边界见[视觉 QA](../design/qa.md)。

小红书既有 Chrome 61 与原生 Storage 迁移事项仍留待后续，不混入本次单一遮挡修复。另一任务的豆包连接器未并入本次发布。
