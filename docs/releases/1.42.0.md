# 1.42.0 发布说明

2026-11-10，维护者确认棋盘预览并授权将稳定 `dev` 提升至 `main`，统一版本为 1.42.0，完成各渠道发行。

- 三维棋盘加入透视与半透明曲面遮挡，保留自交处的可读性。
- 网格与曲面使用同一网格几何，减少轮廓处的虚线和闪烁；棋子支持连续的局部遮挡。
- 二维与三维往返时采用等价的短旋转，避免重复绕行完整圈数。

共享产品基线为 `dev@a18ed73`，版本准备提交 `e38b965` 已提升为稳定 `main@f6c699e`（标签 `v1.42.0`）。提升前后均重新通过 203 项测试、H5 资源与文档校验；同状态浏览器对照、轮廓连续性与局部遮挡证据见[视觉 QA](../design/qa.md)。

## 验证范围与限制

- 用户已确认本轮预览与修复效果。浏览器验证覆盖二维保真、三维交互和六种曲面的遮挡。
- 常见少量棋子场景约 60 帧/秒；19×19 满盘的精确遮挡仍有性能开销，已测约 12–20 帧/秒。
- 桌面自动化与模拟视口不等同于手机真机验收；平台上传、审核与上线分别记录，不混用状态。

### 技能与工具

- Codex 用户级安装 `redapp-cli` 和 `minitool-zip-builder` 1.9.0-beta.20261023.1；路径与引用完整性检查通过，Codex 强制刷新技能列表后两者均为 `user` / `enabled`。`redapp` 对应官方 `redskillhub-upload` 1.0.5，动态门禁返回 `installed`，使用正式环境与官方 latest 版本线。
- 小红书安装初期遇到 npm 依赖请求超时；保留不完整目录作恢复备份后，用同一官方门禁和缓存重新安装成功，未切换源码或版本线。新增 `mini_tool.json`，声明本产品未启用 Worker、OffscreenCanvas、WASM 或第三方引擎；不改变共享游戏。
- Toy Skill 更新至官方 `bilibili/toy@faee502`；CLI 从 0.4.0 升至 0.6.5，官方 SHA-256 校验与最新版本检查通过，旧技能与工具均已备份。当前任务读取新文件执行；后续会话自动发现读取更新后的文件。
- 微信 Skill 0.3.14 与官方安装包一致；知乎 Skill 1.2.0 的官方更新检查为 `current`，两者无需更新。

### 验证范围与外部环节

- 小红书手机预览由用户于 2026-11-10 确认通过，保留原作品名称、简介、图标和封面。新规范要求的 Chrome 61 基线与原生 Storage 完整迁移尚有后续兼容工作；没有把曾在 iPhone 验收失败、未重新确认的兼容分支混入发行。当前浏览器存储有异常保护，但存储不可用时不能保证保存进度。官方体积审计不证明旧内核兼容，创服本地模拟器本轮加载未完成。
