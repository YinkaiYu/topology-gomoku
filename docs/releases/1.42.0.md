# 1.42.0 发布说明

2026-11-10，维护者确认棋盘预览并授权将稳定 `dev` 提升至 `main`，统一版本为 1.42.0，完成各渠道发行。

- 三维棋盘加入透视与半透明曲面遮挡，保留自交处的可读性。
- 网格与曲面使用同一网格几何，减少轮廓处的虚线和闪烁；棋子支持连续的局部遮挡。
- 二维与三维往返时采用等价的短旋转，避免重复绕行完整圈数。

共享产品基线为 `dev@a18ed73`，203 项测试与 H5、文档校验已通过；同状态浏览器对照、轮廓连续性与局部遮挡证据见[视觉 QA](../design/qa.md)。本轮版本提升会重新执行完整检查，各渠道发行结果在完成后记入本文。

## 验证范围与限制

- 用户已确认本轮预览与修复效果。浏览器验证覆盖二维保真、三维交互和六种曲面的遮挡。
- 常见少量棋子场景约 60 帧/秒；19×19 满盘的精确遮挡仍有性能开销，已测约 12–20 帧/秒。
- 桌面自动化与模拟视口不等同于手机真机验收；平台上传、审核与上线分别记录，不混用状态。

## 渠道发行

所有发行渠道接收同一个稳定 `main` 产品提交和 1.42.0 游戏版本；Arena 保留独立服务、提示词和插件功能。渠道整合提交、构建验证、产物与发布结果将在本轮收尾补齐。
