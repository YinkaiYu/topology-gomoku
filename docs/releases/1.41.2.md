# 1.41.2 发布说明

拓扑边界显示修复。2026-11-06 用户确认预览，授权合并、关闭 [Issue #8](https://github.com/YinkaiYu/topology-gomoku/issues/8)、提升 `main` 并完成渠道发行。统一游戏版本为 1.41.2。

- 有拓扑连接的边从最外排落子点向外延伸半格，网格接到彩色辅助线；开放边保留原范围。
- 二维到三维的边界与网格连续转换，常规七关的落子位置、命中和规则保持不变；极小面板容纳完整的辅助线与箭头。
- 归圆上边与左边同为青绿色，右边与下边同为金黄色，动画中保持分组。
- H5 游戏本体和共享 Canvas 绘制模块采用同一套边界几何，微信原生渠道通过共享模块接收行为。

产品提交为半格边界 `c39f4d3`、归圆配色 `9eaf057`。160 项测试、H5 资源与文档校验通过；七关三种视口的 42 组前后页面、180 个曲面状态、42 组共享模块尺寸及跨边五连通过。浏览器模拟视口不等同于宿主真机验证，证据见[视觉 QA](../design/qa.md)。
