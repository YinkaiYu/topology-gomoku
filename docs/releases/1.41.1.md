# 1.41.1 发布说明

关卡卡片比例修复。用户于 2026-10-20 确认本地预览，并明确授权合并、发行，统一版本定为 1.41.1。

- 图案随卡片可用空间调整，恢复归圆的尺寸层级。
- 拓扑标签 / 关卡名为 11 / 17px，极矮窗口为 10 / 15px；长标签保持单行。
- 七张卡片同屏完整显示，首页继续固定、不允许上下滑动。
- 共享 H5 修改覆盖小红书、Bilibili、Web 和知乎。微信原生 Canvas 接收统一版本和共享基线，不机械套用 H5 样式。

验证：151 项测试、H5 包校验、Web 构建，以及 Chromium 人机 / WebKit 双人共 18 个布局与交互场景通过。同视口对比和复现步骤见[视觉 QA](../design/qa.md)。未修改玩法、文案、材质或宿主权限。
