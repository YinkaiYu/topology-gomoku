# 1.40.0 发布说明

本轮为首页排版修正，统一游戏版本为 `1.40.0`，沿 `dev → main → 五个发行分支` 同步。Git 分支、版本标签与构建产物的完成，不代表平台上传、审核通过或线上生效。

## 产品变化与确认

- 删除首页宣传口号，保留“拓扑 / 五子棋”两行左对齐。
- 标题字号增大约 8%，行高调整为 1.2，并向下校正 4 px；品牌图标和关卡列表布局保持原有比例。
- 用户于 2026-10-20 确认最终本地预览，并授权维护者完成 PR、稳定提升和发行同步。
- 同视口前后证据见[视觉 QA](../design/qa.md)，覆盖 390 × 844、360 × 770、360 × 740、320 × 568 与 1280 × 900；验证了字体加载、页面无横向溢出和首关进入返回。

## 验证与发行边界

- 核心验证：119 项测试、H5 包校验、文档链接与 Git 差异校验通过。
- 未引入新的游戏规则、依赖或宿主 API；不合入其他任务分支中尚未确认的功能。
- 微信原生 Canvas 需在平台渲染边界同步标题排版；H5 样式合并不能替代原生适配。
- 渠道整合与线上状态见下方记录；后台人工确认与平台审核不能以构建通过代替。

## 小红书新规范的范围决定

发布后台提供 Skill 1.8.0，已下载并阅读全部相关 reference，核对在线文档。相较其随包 API 快照，新增公开内测能力为 `window.xhs.AI` 文本生成，本游戏没有接入需求。当前项目仍有 Chrome 61 CSS 回退和平台 Storage 接口迁移工作未完成；不能声称满足 1.8.0 完整规范。

用户明确选择“本轮先发布已确认的 UI，完整适配另做”。因此本轮沿用已确认的游戏包；后续兼容样式、存档边界与迁移应从 `dev` 建独立任务，验证并预览确认后再进入稳定版本，不在本轮发行分支复制修补。创服模拟器、Android 真机与 iOS 真机验证结果须分别记录。
